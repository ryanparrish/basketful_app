# Basketful App Documentation

> Last updated: 2026-07-13

This folder contains developer and contributor documentation for the Basketful Django application (backend in `apps/`, admin frontend in `frontend/`, participant frontend in `participant-frontend/`).

See [INDEX.md](INDEX.md) for the full documentation map, organized by system and audience. Key files:
- `SETUP.md` — local development environment setup (backend + both frontends)
- `TESTING.md` — running tests, coverage, and fixture/factory patterns
- `ARCHITECTURE.md` — system architecture, ER/class diagrams, balance calculations
- `PROJECT_STRUCTURE.md` — folder layout and key files
- `CI.md` — GitHub Actions workflows and required secrets/env vars
- `DEPLOYMENT.md` — Render + Docker deployment

If you want additional docs (API, design decisions, onboarding), tell me which ones to add.
